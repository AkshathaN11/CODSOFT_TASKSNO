# Rule-Based Chatbot

## Introduction

This project is a simple rule-based chatbot developed using Python.  
It responds to user messages using predefined rules and pattern matching.

## Objective

The objective of this project is to create a simple chatbot that can understand common user inputs and provide appropriate responses.

## Features

- Responds to common greetings
- Answers basic questions about Python
- Provides information about AI and chatbots
- Responds to programming-related questions
- Handles help requests
- Responds to thanks
- Supports good morning and good night greetings
- Provides an exit option
- Handles unknown questions
- Includes a graphical user interface

## Technologies Used

- Python
- Regular Expressions
- Conditional Statements
- Pattern Matching
- Tkinter
