# Tic-Tac-Toe AI

## Project Overview

This project implements an AI-powered Tic-Tac-Toe game in Python.

The player competes against an AI opponent. The AI uses the Minimax
algorithm to evaluate possible moves and select the best available move.

## Objective

The objective of this project is to implement an AI agent that can play
the classic game of Tic-Tac-Toe against a human player using a basic
search algorithm.

## Features

- Human vs AI gameplay
- AI opponent using the Minimax algorithm
- Automatic move selection by the AI
- Win, loss, and draw detection
- Input validation
- Simple command-line interface

## Algorithm Used

### Minimax

The Minimax algorithm evaluates possible game states and selects a move
that maximizes the AI's chances of winning while minimizing the
opponent's chances.

In this project:

- `X` represents the human player.
- `O` represents the AI player.
- A winning move for the AI receives a positive score.
- A winning move for the human receives a negative score.
- A draw receives a score of zero.

## Technologies Used

- Python
- Minimax Algorithm
- Basic Game Theory
- Command-Line Interface
