# Task 2 - Movie Recommendation System

## Project Overview

This project implements a simple movie recommendation system using
content-based filtering.

The system recommends movies based on the similarity of their genres.

## Dataset

The project uses the MovieLens dataset provided by GroupLens Research.

The dataset contains movie titles and their genres.

## Methodology

1. Load the MovieLens movie dataset.
2. Process the movie genres.
3. Convert genres into numerical features using TF-IDF.
4. Calculate cosine similarity between movies.
5. Accept a movie title from the user.
6. Recommend five similar movies.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
